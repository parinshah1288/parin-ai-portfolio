03 / Components

Layers and neurons are the building blocks.

Layers

Input layers receive features; hidden layers learn transformations; the output layer returns a prediction.

Neurons

Each neuron combines weighted inputs, adds a bias, then applies an activation function.

a = tanh(Σ wᵢ xᵢ + b)

A single neuron is simple; a connected network of them can represent much richer behavior.

05 / Components

Tanh provides nonlinearity.

Tanh ranges from −1 to +1

Without nonlinear activations between layers, a stack of linear transformations is still just a linear transformation.

Why it matters here

A circle needs a curved decision boundary. Hidden layers using Tanh can combine the two features into nonlinear decision patterns.

08 / Hands-on exploration

Change one thing at a time.

A · Baseline

Tanh, 4 + 2 hidden neurons, noise 0. Record epochs and both loss values after training.

B · Add noise

Increase noise to about 20. Check whether the model finds clean separation as easily.

C · Simplify the network

Try one hidden layer, then return to two. Compare convergence and boundary shape.

D · Interpret

A lower training loss alone is not enough; check test loss to look for generalization issues.

10 / Key takeaways

Three ideas connect the whole network.

01 · Structure matters

Layers and neurons determine how features move and are transformed.

02 · Nonlinearity matters

Tanh helps the network represent curved patterns from simple inputs.

03 · Feedback matters

Loss and optimization guide parameter updates over training batches.

04 · Visualization matters

Seeing architecture and predictions together makes model choices easier to understand.
